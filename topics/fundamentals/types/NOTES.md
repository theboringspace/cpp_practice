# Types

There are many fundamental data types in C++. The ones covered here are the simplest ones.

The demo shows 
1. The amount of bytes they need,the minimum value they can contain, and the maximum.
2. Narrowing of values depending on the method if initialization.
  - Copy-initialization ( int x = 3 ) 
  - Direct-initialization ( int x(3) )
  - Direct-list-initialization ( int x{3} )
  - Copy-list-initialization ( int x = {3} )
